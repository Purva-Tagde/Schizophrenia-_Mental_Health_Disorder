# Schizophrenia-_Mental_Health_Disorder
🧠 AI-Powered Schizophrenia Early Detection System

📌 Project Overview
Schizophrenia-_Mental_Health_Disorder is a full-stack clinical decision support web application that leverages machine learning to assist medical professionals in the early detection of schizophrenia. The system analyzes a combination of psychiatric scale scores, demographic information, behavioral symptoms, and lifestyle factors to generate a comprehensive risk probability score for each patient.
The project bridges the gap between raw ML model outputs and real-world clinical usability by wrapping a trained Random Forest classifier inside a professionally designed, interactive web interface — making AI-driven insights accessible to psychiatrists, neurologists, and clinical researchers without requiring any technical background.

🎯 Problem Statement
Schizophrenia affects approximately 1 in 300 people globally and is one of the most debilitating psychiatric disorders. A critical challenge in treatment is late diagnosis — most patients are only identified during acute psychotic episodes, by which point significant neurological and social damage has already occurred.
Early-stage (prodromal) detection can reduce long-term disability, lower hospitalization rates, and dramatically improve quality of life. However, prodromal symptoms are subtle and often missed in routine clinical settings. NeuroSense addresses this gap by providing a structured, data-driven screening tool.

⚙️ Key Features
Multi-factor Risk Assessment — Evaluates 40+ clinical parameters including PANSS scores, GAF scores, PHQ-9 depression scale, family history, substance use, sleep patterns, and stress levels
Symptom Checklist Engine — Structured selection of 10 clinically validated psychiatric symptoms with real-time weighting
Risk Score Output — Produces a percentage-based risk probability with High / Low classification and model confidence score
Factor Breakdown Panel — Visual breakdown of the 6 most influential input features contributing to the prediction
User Authentication System — Secure login and registration with role-based access (Psychiatrist, Psychologist, Researcher, etc.)
Responsive Web Interface — Fully functional across desktop, tablet, and mobile devices
Contact & Collaboration Portal — Integrated contact form for clinical partnerships and research inquiries
